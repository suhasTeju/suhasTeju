## About me

I build AI products end to end and ship them alone at the pace of a team. Seven years as a software engineer, the last few building LLM systems that run in production: agents with tool use, retrieval over large document sets, real-time voice, and small fine-tuned models that replace expensive large ones. Backend, frontend, native iOS and the cloud underneath are all mine.

## Stack

### Agentic layer

| | |
|---|---|
| **Models** | OpenAI GPT-5 and GPT-6 family, Anthropic Claude, open-weight models (gpt-oss, GLM, DeepSeek, MiniMax, Mistral) through AWS Bedrock and Ollama Cloud, routed by task and cost with fallback chains |
| **Agents** | Tool-calling agents with planning, guardrails and memory; a Telegram and WhatsApp study agent with 70+ tools; proactive agents that nudge, monitor and triage |
| **Retrieval** | Qdrant, LightRAG knowledge graphs, Cohere rerank, HyDE and multi-query retrieval over textbooks and PDFs; Mistral OCR for ingestion |
| **Voice** | Deepgram Voice Agent (Flux, Nova-3, Aura-2), Sarvam Bulbul and Saaras for Indian languages, ElevenLabs; sub-second turn-taking in production |
| **Generation** | Lecture and animation pipelines: LLM-written scripts, agent-driven board drawing, ManimGL, self-hosted lip-sync (SoulX FlashHead) and voice (OmniVoice) on L4 and L40S GPUs |
| **Small models** | Fine-tuned 0.8B models replacing API calls; self-hosted inference where it beats the bill |
| **Ops** | Per-call cost and token telemetry, PromptLayer, PostHog, prompt-injection defence with server-side agent configs |
| **Building with agents** | Claude Code and Codex CLI for daily development; agents run support, monitoring and code review |

### 📦 pdfjs-reader-core

[![npm version](https://img.shields.io/npm/v/pdfjs-reader-core?style=flat-square)](https://www.npmjs.com/package/pdfjs-reader-core)
[![npm downloads (weekly)](https://img.shields.io/npm/dw/pdfjs-reader-core?style=flat-square)](https://www.npmjs.com/package/pdfjs-reader-core)
[![GitHub stars](https://img.shields.io/github/stars/suhasTeju/pdf-reader-js?style=flat-square)](https://github.com/suhasTeju/pdf-reader-js/stargazers)
[![License](https://img.shields.io/github/license/suhasTeju/pdf-reader-js?style=flat-square)](https://github.com/suhasTeju/pdf-reader-js/blob/main/LICENSE)

A PDF reading and parsing library on top of PDF.js: canvas rendering, text extraction, programmatic highlights and annotations, full-text search, usable from React, Vue or plain JS. Built because every document viewer and annotation tool I made started with the same plumbing.

```bash
npm install pdfjs-reader-core
```
