## 🧩 Open Source Contributions

### 📦 pdfjs-reader-core
🔗 **NPM**: https://www.npmjs.com/package/pdfjs-reader-core  
🔗 **GitHub**: https://github.com/suhasTeju/pdf-reader-js  

An open-source **core PDF reading and parsing library** built on top of **PDF.js**, designed to abstract low-level PDF handling into a clean, reusable module for modern web applications.

**Key highlights:**
- 📄 Simplifies PDF.js integration via a structured core layer
- 🧩 Enables building **custom PDF viewers**, document pipelines, and reader tools
- ⚡ Framework-agnostic — works with React, Vue, or vanilla JavaScript
- 🌍 Actively published and maintained on **NPM**
